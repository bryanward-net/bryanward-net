When manually running the RRM process via Network>Radio Management, the “Optimize Now” button only triggers the RRM process for the band that is currently displayed. If you want to optimize both 2.4GHz and 5GHz, you need to switch to displaying the 2.4GHz Band, click “Optimize Now”, then switch to the 5GHz Band, and click “Optimize Now” again.
